# Start-risici

- Faktisk Godot-version og eksporttemplates skal auditeres.
- Konkrete Synty-/PolyPerfect-modeller og klip skal findes og kontrolleres; referencer er ikke produktkataloger.
- Forecast/state/event-paritet er højeste tekniske risiko.
- Web/iOS-paritet kræver faktisk eksport og fysisk test.
- Visuel rigkvalitet kan ikke bevises headless.

Registrér reproduktion, påvirket gate og næste handling ved konkrete blokeringer.
