# LR-24 · Farveblindhedssimulering

`python3 tools/colorblind_sim.py evidence/colorblind <billeder…>` (Machado 2009, styrke 1,0, lineær RGB). `*_strip.jpg`: original (øverst t.v.), protan (ø.h.), deutan (n.v.), tritan (n.h.).

Gennemgang 21.10 af kamp (midt + boss), kortoversigt og rutekort:
- Prognosens grønne (sikker) og orange (fare) linjer bliver næsten ens gule ved protan/deutan, men bærer altid egne glyffer (♥, ↑, ✝) og tal → ingen information alene i farve.
- Bark (rav) og Spore (violet) kortrammer forbliver adskilte (gul/blå) i alle tre; type står også som tekst ("Creature"/"Spell").
- Statusser vises som glyf + tal (◆ rustning, ☠ gift, ✶ torne) i alle simuleringer.
- Svagest: tritan gør turkis Saft-ikon og grøn hjerte-HP rødlige; tallene står stadig.
Konklusion: ingen fund, der kræver ændring nu. Gentages med Synty-grafik og endelig palet (LR-13/24).
