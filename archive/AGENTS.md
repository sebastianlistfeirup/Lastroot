# LASTROOT - agentmandat

Brugerens seneste instruktioner og gældende sikkerhedsregler går først. Læs START_HERE.md og docs/BIBLE.md helt.

1. HOLIDAY: én agent, ingen delegation. FULL ved hjemkomst: én integrator og højst to afgrænsede specialister når tilladt og tilgængeligt.
2. Bevar eksisterende kode og brugerændringer; auditér før nyt repository. Ingen destruktiv reset.
3. Brug Godot/GDScript og validerede Synty-/PolyPerfect-imports. Opret ikke webapp i TypeScript som erstatning.
4. Ren BattleReducer er eneste autoritet. Forecast bruger samme kode på en fuld klon. Animation påvirker aldrig udfaldet.
5. tasks.json har 36 opgaver og fire faser. DONE kræver commit, faktiske tests og evidence. NOT_RUN er ikke PASS.
6. Ingen nye fraktioner, etager, multiplayer eller metaprogression uden nyt mandat.
7. Katalogtal er baseline. Balancér med seed, før/efter og dokumenteret begrundelse.
8. Originale vendorassets bevares; wrappers og egne varianter er projektejede. Ingen rå købte pakker i offentligt repository.
9. Efter tre forskellige fejlhypoteser: minimal repro, checkpoint og anden READY-opgave hvis mulig. Opfind aldrig assetpaths, API-adgang eller testresultater.
10. Arbejd videre på reversible opgaver uden løbende bekræftelser. Køb, eksterne beskeder og publicering følger faktisk brugerautorisation; færdiggør reviewpakken før sidste nødvendige stop.
11. Hver opgave afsluttes med commit og opdaterede docs/STATUS.md, docs/DECISIONS.md, plan/tasks.json og evidence.
12. Gamle source-PDF’er i archive er historik. V2-afklaringer i BIBLE.md er den gældende regelbaseline.
